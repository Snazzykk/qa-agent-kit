# OOP-паттерны pytest

Сначала проверь текущие тесты и правила проекта. Если они используют тестовые классы, сохраняй их
иерархию и точки переиспользования. Для функционального стиля или нового Python API-проекта с
blueprint `python-api-template` используй [qa-project-style](../qa-project-style/SKILL.md).

При явно выбранной OOP-архитектуре прочитай [справочник OOP](references/oop-patterns.md).
Применяй только подходящие примеры: существующие клиенты, фикстуры, assertions и раскладка имеют
приоритет. Обоснуй новую базовую абстракцию через конкретную потребность текущей задачи.
